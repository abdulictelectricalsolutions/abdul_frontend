# Abdul ICT & Electrical Solutions

Responsive business homepage inspired by the supplied reference screenshot, built with Next.js App Router, TypeScript, Tailwind CSS v4 and Lucide React icons.

## Run locally

```bash
npm install
npm run dev
```

Includes responsive navigation, services, electronics product cards, product search, interactive cart, WhatsApp order handoff, training promotion, testimonials and contact footer. Product photography uses Unsplash placeholders; replace with verified business/product assets before production.
